# 费用按市场价计算 + 仪表盘展示市场价

## 背景
已通过 Web 搜索查得各模型官方市场价（元/百万 tokens）：
- deepseek-v4-flash：¥1 / ¥2（DeepSeek 官方）
- glm-5.2：¥8 / ¥28（智谱官方）；k3：¥20 / ¥100（Kimi 开放平台）
- gpt-5.6-sol / gpt-5.5：$5/$30 → ¥34 / ¥204（OpenAI，按汇率 6.8）
- claude-opus-5 / claude-opus-4-7：$5/$25 → ¥34 / ¥170（Anthropic）
- gpt-5.6-luna：$1/$6 → ¥6.8 / ¥40.8
- 现有 deepseek-chat / glm-4 / gpt-4o 等一并校正为官方价

## 改动内容

### 1. `server/src/data/prices.json` 更新为市场价
- 数据中出现的 10 个模型全部配置市场价（deepseek-v4-flash-0731 同 v4-flash；GLM-5.2 与 glm-5.2 同价）
- 格式保持 `{ "模型": { "input": 元/1K, "output": 元/1K } }`，费用计算逻辑不变，保存即生效

### 2. API 返回单价
- `GET /api/stats/models` 每条增加 `input_price` / `output_price`（元/1K）与 `price_per_million`（元/百万，展示用）
- 新增 `GET /api/prices`：返回全部模型市场价列表（模型名、渠道、输入/输出单价 元/百万）

### 3. 前端展示市场价
- **新增「模型市场价参考」面板**（明细表上方全宽）：表格展示 模型 / 渠道 / 输入单价 / 输出单价（元/百万 tokens），来源标注「官方市场价（2026-08 查询，汇率 6.8）」；行尾显示该模型累计费用，方便核对
- **ModelBar 图表 tooltip** 增加 输入/输出单价
- **费用 KPI 卡片** 副标题注明「按市场价估算」

### 4. 验证
- curl 验证 models / prices 接口返回单价
- 页面渲染检查新面板与图表 tooltip 数据
- 费用数值随市场价自动重算（gpt-5.6-sol 单价上调后总费用将显著变化，符合市场价口径）

## 说明
- 美元计价模型按汇率 6.8 换算（媒体引用值），如需其他汇率直接改 prices.json 对应数值
- 中转渠道（AkuCb AI 等）实际收费可能低于/高于官方价，面板将保留一行提示
