# TokenView 一体化产品化：安装包 + 无窗口运行

## 目标
交付正式软件形态：**安装包（setup.exe）+ 无黑窗口运行 + 桌面/开始菜单快捷方式 + 单实例保护**。双击快捷方式即静默启动服务并自动打开浏览器界面，数据落在规范位置。

## 形态设计
```
TokenView-Setup.exe（Inno Setup 安装包，per-user 免管理员）
└── 安装到 %LOCALAPPDATA%\Programs\TokenView\
    ├── TokenView.exe          （单文件自包含，现有构建产物）
    ├── TokenView-run.vbs      （隐藏窗口启动器）
    ├── 开始菜单 + 桌面快捷方式（指向 vbs，带 --data-dir 参数）
    └── 卸载程序（先结束运行中的 TokenView 进程）
数据 → %LOCALAPPDATA%\TokenView\data\reports.jsonl
日志 → %LOCALAPPDATA%\TokenView\logs\server.log
```

## 运行时增强（index.js / runtime.js）
1. **单实例保护**：启动时先探测默认端口——若已是 TokenView（`/api/health` 返回 TokenView server OK），则只打开浏览器并退出，不重复启动第二个实例
2. **`--data-dir` 参数**：优先级 参数 > TOKENVIEW_DATA_DIR > exe 同目录 data/ > %LOCALAPPDATA%\TokenView\data（安装版快捷方式显式传入）
3. **文件日志**：stdout 不可用（vbs 隐藏窗口）时，`console.log/error` 自动 tee 到 `logs/server.log`（按日滚动，保留 7 天）
4. 自动打开浏览器逻辑不变（`--no-browser` 可关）

## 隐藏窗口启动器（TokenView-run.vbs）
```vbs
CreateObject("Wscript.Shell").Run "..."TokenView.exe" --data-dir "..."", 0, False
```
无黑窗口；进程常驻后台，浏览器为唯一界面（卸载/任务管理器可退出）

## 安装包构建（新增 server/installer/）
1. winget 安装 **Inno Setup 6**（iscc 编译器）
2. 编写 `tokenview.iss`：AppName=TokenView、per-user 安装（免 UAC）、安装 TokenView.exe + 生成 vbs、创建开始菜单/桌面快捷方式、卸载时 taskkill TokenView
3. `npm run build:setup` 一键：build:exe → iscc 编译 → 产出 `TokenView-Setup.exe`
4. 绿色版（单文件拷贝）行为保持不变，README 分别说明

## 验证
1. 构建 `TokenView-Setup.exe`
2. 静默安装到本机（iscc 或安装包 /SILENT）→ 快捷方式生成确认
3. 通过 vbs 启动 → 无窗口进程存在 + API 正常 + 浏览器自动打开（headless 环境验证到启动日志）
4. 重复启动 → 单实例：不新增进程，浏览器打开已运行实例
5. 数据写入 %LOCALAPPDATA%\TokenView\data、日志写入 logs/
6. 卸载验证（卸载后进程/目录清理）

## 说明
- 进程常驻后台，退出方式：任务管理器结束 / 卸载程序（README 说明）
- 安装包约 60-70 MB（exe 94MB 压缩后）
- 开发模式（npm run dev）完全不受影响
