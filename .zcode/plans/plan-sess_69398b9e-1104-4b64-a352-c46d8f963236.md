# 工具统计维度：13 个 code 工具全覆盖

## 目标
仪表盘新增「工具统计」维度，覆盖 13 个工具：zcode、claude code、codex、CodeBuddy CN、JoyClaw、kimi、LobsterAI、OpenSquilla、qoder、Trae CN、TRAE SOLO CN、Trae、WorkBuddy。有本地数据的写适配器直读；无本地数据的通过上报接口统计。

## 数据源能力分级（已探查）

| 级别 | 工具 | 方案 |
|---|---|---|
| ✅ 有明文数据 | codex（5,782 条）、WorkBuddy（336 条）、LobsterAI（13 条） | 写适配器 |
| ⚠️ 结构就绪 | JoyClaw（usage-state.json，当前 0 条） | 写适配器（预留） |
| 🔒 加密数据 | CodeBuddy CN、Qoder（VS Code secret storage，v10t+DPAPI+AES） | 写解密适配器（best-effort，失败标记"解密失败"） |
| ❌ 无本地数据 | Trae / Trae CN / TRAE SOLO CN（会话在服务端）、kimi / OpenSquilla（未安装） | 上报接口（新增 tool 字段） |

## 后端改动

### 1. 新适配器（server/src/data/）
- **codex.js**：扫描 `~/.codex/sessions/**/rollout-*.jsonl` + `archived_sessions/`；`token_count` 事件取 `last_token_usage` 增量（输入/输出/缓存/推理 tokens）；模型名从同文件 `turn_context` 按时间 join；增量按文件 mtime 缓存
- **workbuddy.js**：扫描 `~/.workbuddy/projects/*/*.jsonl`；取 `providerData.rawUsage`（prompt/completion/total + cached）；模型本地只记 "auto"（备注注明）
- **lobsterai.js**：扫描 `AppData\Roaming\LobsterAI\openclaw\state\agents\main\sessions\*.jsonl`（Claude Code 格式：`message.usage.input/output/cacheRead/cacheWrite/reasoningTokens/totalTokens`）
- **joyclaw.js**：读 `AppData\Roaming\JoyClaw\state\desktop-token-usage-state.json`（sessions map 增量，当前为空）
- **codebuddy-cn.js / qoder.js**：读 `state.vscdb` 的 secret key → Local State 取 DPAPI 加密的 AES key（Node 调 PowerShell `ProtectedData::Unprotect`）→ AES-256-GCM 解密 v10t → 解析用量 JSON；失败返回空并标记

### 2. 统一行结构
`source` 字段即工具标识（zcode / claude-code / codex / workbuddy / lobsterai / joyclaw / codebuddy-cn / qoder / api），`stats.js` 的 `getAllRows()` 合并全部适配器

### 3. 新接口 `GET /api/stats/tools`
返回固定 13 工具清单 + 每工具聚合：`calls / tokens / cost / 状态（有数据·无数据·解密失败·待上报）/ 最近使用时间`；无数据工具显示 0（保证 13 行完整）

### 4. 上报 API 扩展
body 增加可选 `tool` 字段（工具名），写入 reports.jsonl；工具统计中上报数据按 tool 归组，未填 tool 归入"api"

## 风险与说明
- **CodeBuddy CN / Qoder 解密为 best-effort**：v10t 格式或 DPAPI 调用异常时标记"解密失败"，工具行仍显示（0 数据），可通过上报接口统计
- **Trae 系列 / kimi / OpenSquilla** 本地确实无用量数据（会话在云端/未安装），只能依赖上报接口；如需自动采集需云端 API，本次不做
- 数据源路径全部可经环境变量覆盖（`.env`）
